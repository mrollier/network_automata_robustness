# Network automata robustness

Robustness of Life-Like Network Automata (LLNA): defect propagation, Lyapunov
spectra, Derrida maps, and mean-field behaviour of density-based binary
automata on networks.

> **Note** — this repository is mid-cleanup (2026-07). This README is a
> placeholder and will be rewritten with install and usage instructions once
> the `llna` package lands.

Layout:

- `src/` — the LLNA implementation and analysis library
- `manuscript/` — figure-generating notebooks + data for the robustness paper
- `experiments/` — living research notebooks
- `notebooks/` — (coming) explanatory notebooks
- `tests/` — automated test suite + characterization fixtures
- `archive/` — stale one-off notebooks, kept for reference (outputs stripped)
- `legacy/` — the original TEP pipeline by Lucas Caldeira (unmaintained, see `legacy/README.md`)
- `csf-submission/` — the CSF Lyapunov paper submission (figures live in the separate `exact-lyapunov-spectra` repo)
- `presentation/` — talk figure generators
